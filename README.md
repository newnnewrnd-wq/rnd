# NEW&NEW Formula Lab

**직원 계정으로 로그인하는 독립 실행 버전:** [설치·운영 안내](standalone/README.md)를 확인하세요. Windows는 Node.js 24 LTS 설치 후 `start-windows.bat`로 시작합니다. `standalone/` 서버가 로그인과 계정 관리를 담당하며, 아래 `dist/`는 배합 계산 화면입니다.

한국어 화장품 배합 계산 및 입력 규격 검토 도구. 의존성 없는 정적 HTML/CSS/JavaScript 사이트입니다.

## 기능

- 43종의 편집 가능한 원료 카탈로그 및 직접 입력
- 수분 세럼, O/W 크림, 계면활성제 클렌저 계산 예시와 빈 처방
- 공급 원료 기준 w/w 배합비와 제조량 g/kg 변환
- 정제수 q.s. 및 원료 간 비율을 유지하는 100% 환산
- 유효분에 따른 완제품 % / ppm 환산
- 단가 입력 범위를 명시한 배치 원료비 계산
- 원료별 사용 범위, 적용 pH 범위, 공통 pH 구간 비교
- 투입상 구성 차트, 입력 오류 안내, 한국어 CSV 다운로드

## 계산 정의

투입량 (kg) = 설정 제조량 (kg) × 공급 원료 배합비 (%) / 100.
유효분 환산 (%) = 공급 원료 배합비 (%) × 공급 원료 내 유효분 (%) / 100.
ppm = 유효분 환산 (%) × 10,000.
원료비 (원) = 투입량 (kg) × 공급 원료 단가 (원/kg).

배합 총합이 100%가 아니면 실제 합산 투입량은 설정 제조량과 다릅니다. 자동 정규화하지 않습니다. 단가 미입력은 0원으로 간주하지 않으며 부분합과 단가 입력 수를 함께 표시합니다. 정제수 외 원료가 100%를 넘으면 q.s. 작업은 원래 처방을 변경하지 않고 실패합니다.

## 범위와 데이터

카탈로그의 역할과 투입상은 편집 가능한 예시이며, 공급 원료 규격이나 실제 제조공정을 대신하지 않습니다. 내장 처방과 유효분 숫자는 계산 예시입니다. 규격별 권장 사용량 또는 법정 허용량을 내장하지 않으며, 범위 비교는 사용자가 직접 입력한 값만 사용합니다.

최종 pH, 점도, 용해도, 유화 안정성, 성분 간 화학적 상용성, 효능, 보존력, 법규 적합성은 예측하거나 보증하지 않습니다. 공통 pH 구간은 입력 범위의 교집합이며 혼합물의 pH 계산값이 아닙니다. 보존 관련 분류는 보존력 또는 규제상 보존제 분류에 대한 판정이 아닙니다.

입력값은 메모리에서만 처리합니다. 서버 전송·자동 저장·분석 추적이 없으며 새로고침 시 초기화됩니다. CSV는 배합 및 규격 정보를 포함하지만 앱으로 재가져오기는 지원하지 않습니다. 웹 페이지와 자바스크립트는 외부 CDN, API, 폰트를 요구하지 않습니다.

## 소스

- dist/index.html: 한국어 화면과 모달
- dist/style.css: 반응형 테마
- dist/data.js: 원료 카탈로그와 계산 예시
- dist/engine.js: 입력 검증, 계산 및 규격 비교
- dist/app.js: 화면 상태와 동작, CSV, 선택적 WebMCP 등록

WebMCP는 지원되는 브라우저에서 get_formula_state / set_formula_inputs를 등록합니다. 지원 환경 검증은 수행하지 않았습니다(이 작업은 브라우저 테스트를 포함하지 않음). 일반 웹 사용에는 WebMCP가 필요하지 않습니다.
